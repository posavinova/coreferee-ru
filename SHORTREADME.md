Coreference occurs when two or more expressions in a text refer to the same entity - for example, "**Мария** уехала в отпуск, потому что **она** слишком устала от работы".

`coreferee-ru` is a Python library for coreference resolution in  Russian, designed to work with [spaCy](https://spacy.io/). It is a Russian-language adaptation of the [Coreferee](https://github.com/richardpaulhudson/coreferee) framework and preserves its core interface while providing Russian-specific rules and trained models. It uses a combination of neural models and programmed rules.

For installation instructions, usage examples, supported versions, see the [main README](https://github.com/posavinova/coreferee-ru/blob/main/README.md).
